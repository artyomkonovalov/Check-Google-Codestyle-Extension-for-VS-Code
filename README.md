## 🚀 Возможности расширения

Расширение позволяет проверять соблюдение google-кодстайла при разработке на C++ 

### 🔍 Основной функционал:

- **✅ Проверка именования переменных** - должен использоваться `snake_case`
- **✅ Проверка именования констант** - должен использоваться `kConstName` 
- **✅ Проверка именования функций** - должен использоваться `PascalCase`
- **✅ Проверка форматирования управляющих структур** - пробелы после `if`, `while`, `for`
- **✅ Проверка расположения фигурных скобок** - должны быть на той же строке что и условие
- **✅ Исключение для функции `main`** - не проверяется на соответствие PascalCase
